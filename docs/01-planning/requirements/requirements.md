> 상태: **확정** (2026-11-19, §6)
> 작성일: 2026-11-19
> 근거 문서: [프로젝트 목표](../../00-overview/project-goals.md), [포인트 정책](../policies/point-policy.md), [리뷰 정책](../policies/review-policy.md), [ERD](../../03-architecture/database/erd.md), [API 명세](../../03-architecture/api/api-spec.md), [ADR-002](../../07-meetings/decisions/ADR-002-tech-stack.md), [ADR-003](../../07-meetings/decisions/ADR-003-social-login.md)

이 문서는 **무엇을 만들지**를 정한다. 세부 규칙(금액, 한도, 상태 전이 등)은 정책 문서에 있고, 여기서는 해당 절을 참조만 한다.

## 1. ID 규칙과 우선순위

| 접두어 | 대상 | 번호 대역 |
|---|---|---|
| `REQ` | 웹과 앱 공통 기능 | 001~099 인증·계정, 100 게임, 200 출시 일정, 300 리뷰, 400 커뮤니티, 500 출석·포인트·랭킹, 600 마이페이지·알림, 700 이벤트·공지, 800 평가단 미션, 900 비기능 |
| `WEB` | 웹 전용 기능 (홈페이지, 관리자) | 001~099 홈페이지, 100~ 관리자 |
| `MOB` | Unity 앱 전용 기능 | 001~ |

| 우선순위 | 의미 |
|---|---|
| **P1** | 1차 오픈 필수 |
| **P2** | 1차 오픈 이후 |

- 와이어프레임, 테스트 케이스(`TC-###`)는 이 ID를 참조한다.
- 요구사항을 없애면 번호를 재사용하지 않고 "삭제"로 표시한다.

| # | 질문 | 결정 |
|---|---|---|
| 1 | 출시 알림 푸시(FCM)를 1차 오픈에 넣을 것인가? | **앱 푸시(FCM)는 1차 포함**, 웹 실시간 알림(Reverb)은 이후 (REQ-205, REQ-608) |
| 2 | 이벤트를 1차 오픈에 넣을 것인가? (포인트 사용처가 이벤트 응모뿐) | **기본 이벤트(관리자 등록·응모·당첨 지정)는 1차 포함**, 자동화는 이후 (REQ-701~705) |
| 3 | 1차 앱에 커뮤니티(게시판)를 넣을 것인가? | **1차 앱은 커뮤니티 제외**, 웹에서만 제공 (MOB-008) |
| 4 | 첨부 이미지 제한은? | **jpg·png·webp·gif, 1개 10MB, 글당 10개** (REQ-408) |
| 5 | 응답 속도 목표는? | **95%가 500ms 이내** (REQ-906) |
| 6 | 지원 OS 최소 버전은? | **Android 8 이상, iOS 16 이상.** Unity 6 지원 범위를 4단계에서 다시 확인 (REQ-911) |
| 8 | 앱에 "다른 앱 설치 + 구글 플레이 별점·리뷰 시 보상" 탭을 둘 것인가? | **두지 않는다.** Google Play·App Store가 보상형 별점·리뷰를 금지하고, 우리 앱이 삭제될 위험이 있으며, 외부 리뷰 작성을 확인할 수도 없다. 대신 **우리 사이트 리뷰에 보상하는 "평가단 미션"을 2차에 추가**한다 (§2.9, MOB-009) |
| 7 | 닉네임 길이는? | **2~12자** (REQ-004). DB 컬럼은 탈퇴 익명값(`withdrawn_{id}`)이 들어가도록 `varchar(20)`을 유지하고, 길이 제한은 입력 검증으로 한다 |
