# 프로젝트 목표

> 작성 기준: 2026-11-19
> 근거 문서: [게임평가단 통합 기술 개발 설계서](./game-evaluation-development-design.md)

## 1. 최종 목표

**게임평가단 통합 플랫폼 구축.** 홈페이지, 관리자, Unity 모바일 앱(Android/iOS)이 하나의 Laravel 백엔드와 PostgreSQL 데이터베이스를 함께 쓰는 게임 커뮤니티 서비스를 만든다.

플랫폼은 다음 기능을 제공한다.

- 게임 정보 및 출시 일정
- 이용자 평가 및 리뷰
- 커뮤니티(게시판·댓글)
- 출석, 포인트, 등급·랭킹
- 이벤트 및 알림

## 2. 기술 목표

| 목표 | 기준 |
|---|---|
| 단일 백엔드 | 홈페이지·Unity 앱·Filament 관리자가 같은 Laravel 백엔드를 쓴다 |
| 단일 원본 DB | 모든 서비스 데이터를 PostgreSQL 하나에 저장한다 |
| 통합 계정 | 웹과 앱은 인증 방식만 다르고, 회원 계정과 권한 체계는 같다 |
| API 기반 앱 | Unity 앱은 DB에 직접 접속하지 않고, 버전이 붙은 HTTPS REST API(`/api/v1`)만 쓴다 |
| 데이터 무결성 | 포인트·출석·리뷰 추천은 트랜잭션과 UNIQUE 제약으로 중복 처리를 막는다 |
| 로직 재사용 | 비즈니스 로직은 서비스 계층에 두고 웹·API·관리자가 함께 쓴다 |

## 3. 1차 오픈 목표 (필수 기능)

- [ ] Google·Apple 로그인 및 가입 완료 (약관 동의·닉네임)
- [ ] 게임 목록 및 상세 정보
- [ ] 게임 검색 및 필터
- [ ] 게임 리뷰 및 별점
- [ ] 출시 일정
- [ ] 게시판 및 댓글
- [ ] 출석 및 포인트
- [ ] 마이페이지
- [ ] 관리자 게임·회원·리뷰 관리
- [ ] 기본 이벤트 (관리자 등록, 포인트 응모, 당첨 지정) — 포인트 사용처 (요구사항 §6-2)
- [ ] 앱 푸시 알림 (출시 알림 등, FCM) (요구사항 §6-1)
- [ ] Unity 로그인 및 핵심 API 연동

### 이후 확장 목표

- 랭킹 고도화
- 이벤트 자동화
- 고급 통계
- 웹 실시간 알림 (Laravel Reverb)
- 앱 커뮤니티(게시판) 기능 (1차는 웹에서만 제공)

상세 요구사항과 우선순위는 [요구사항 정의서](../01-planning/requirements/requirements.md)를 따른다.

## 4. 단계별 일정 목표

| 단계 | 개발 내용 | 예상 기간 |
|---|---|---:|
| 1단계 | Laravel, DB, 회원 인증, 관리자 기본 구성 | 2~3주 |
| 2단계 | 게임 정보, 검색, 상세 페이지, 출시 일정 | 3~4주 |
| 3단계 | 리뷰, 커뮤니티, 출석, 포인트, 랭킹 | 4~6주 |
| 4단계 | Unity API, 앱 푸시, 테스트 | 4~6주 |

전체 예상 기간은 13~19주다. 개발 인원, 디자인, 콘텐츠 준비, 앱 스토어 심사에 따라 달라질 수 있다.
