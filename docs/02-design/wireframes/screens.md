# 화면 설계 (와이어프레임)

> 상태: **확정** (2026-11-19, §6)
> 작성일: 2026-11-19
> 근거 문서: [요구사항 정의서](../../01-planning/requirements/requirements.md), [API 명세](../../03-architecture/api/api-spec.md), [ADR-002](../../07-meetings/decisions/ADR-002-tech-stack.md)

화면 목록과 화면별 구성 요소를 정한다. 시각 디자인(색, 글꼴, 간격)은 스타터 키트의 shadcn-vue 컴포넌트를 기준으로 개발하면서 다듬는다. 각 화면의 요구사항 ID는 1단계 이후 화면 개발 체크리스트로 쓴다.

## 1. 화면 ID 규칙과 공통 상태

| 접두어 | 대상 |
|---|---|
| `W-##` | 홈페이지 (Inertia) |
| `M-##` | Unity 앱 |
| `ADM-##` | 관리자 (Filament) |

모든 목록·상세 화면은 다음 상태를 처리한다.

| 상태 | 표시 |
|---|---|
| 불러오는 중 | 스켈레톤 (웹 첫 화면은 SSR이라 해당 없음) |
| 비어 있음 | 안내 문구 + 다음 행동 버튼 (예: "첫 리뷰를 남겨 보세요") |
| 오류 | 오류 문구 + 다시 시도 |
| 로그인 필요 | 행동 버튼을 누르면 로그인 화면으로 이동, 로그인 후 원래 화면으로 복귀 (WEB-007) |
| 포인트 지급 | 화면 하단 토스트 "+10P (잔액 1,250P)". 한도 도달 시 "오늘 받을 수 있는 포인트를 모두 받았어요" (REQ-506) |

### 2.2 공통 레이아웃

```
┌──────────────────────────────────────────────────────────────┐
│ [로고]  게임  출시일정  커뮤니티  랭킹  이벤트   [🔍 게임 검색  ]│
│                              [출석✓] [🔔3] [닉네임 · 1,250P ▼] │
├──────────────────────────────────────────────────────────────┤
│                         (페이지 본문)                         │
├──────────────────────────────────────────────────────────────┤
│ 공지 · 이용약관 · 개인정보 처리방침 · 문의                      │
└──────────────────────────────────────────────────────────────┘
```

- 헤더(WEB-002): 검색창은 Enter 시 `/games?q=`로 이동. 출석 버튼은 오늘 출석했으면 체크 표시, 안 했으면 누르면 바로 출석(REQ-501).
- 로그아웃 상태: 출석·알림·닉네임 대신 [로그인] 버튼.
- 닉네임 메뉴: 마이페이지, 설정, 관리자(역할이 있을 때), 로그아웃.
- 모바일 폭(WEB-006): 메뉴는 햄버거 버튼, 검색창은 아이콘으로 접음.

#### W-06 리뷰 작성·수정

```
┌──────────────────────────────────────────┐
│ [표지] 젤다의 전설: ○○○ 리뷰 쓰기          │
├──────────────────────────────────────────┤
│ 종합 점수 (필수)                          │
│ ① ② ③ ④ ⑤ ⑥ ⑦ ⑧ [⑨] ⑩                   │
│                                           │
│ 세부 점수 (선택)               [접기 ▲]    │
│ 그래픽  ① ... ⑩   사운드  ① ... ⑩          │
│ 스토리  ① ... ⑩   조작감  ① ... ⑩          │
│ 게임성  ① ... ⑩   가성비  ① ... ⑩          │
│                                           │
│ 플레이한 플랫폼 [PS5 ▼]                    │
│ 제목   [                        ] 0/50    │
│ 본문   [                              ]   │
│        [                              ]   │
│                              50자 이상 0/5000│
│ [ ] 스포일러가 포함되어 있어요             │
│                                           │
│ [취소]               [ 등록하기 (+100P) ] │
└──────────────────────────────────────────┘
```

- 들어올 때 확인하고, 다음 경우 작성 대신 안내만 표시: 리뷰 작성 제한 중(REQ-312, 종료일 또는 "영구"), 이미 리뷰가 있음(REQ-302, 내 리뷰로 이동), 관리자가 숨긴 리뷰가 있음.
- 오늘 리뷰 포인트 한도를 넘었으면 버튼의 "+100P"를 빼고 "오늘 리뷰 포인트는 모두 받았어요" 표시.
- 수정 모드: 같은 화면, 버튼은 [수정하기], 포인트 표시 없음.
- 작성 중 페이지를 떠나면 "작성 중인 내용이 사라집니다" 확인.

#### W-07 리뷰 상세

- 게임 정보(표지·제목, W-05 링크), 종합·세부 점수, 플랫폼, 작성일, "수정됨"
- 본문 (스포일러면 접힘)
- [👍 추천] (본인 리뷰는 숨김), [신고] (본인 리뷰는 숨김, 이미 신고했으면 "신고함")
- 본인 리뷰: [수정] [삭제]. 삭제 확인 창에 "삭제 후 다시 써도 리뷰 포인트는 받을 수 없어요"(REQ-307)
- 댓글 목록(오래된 순) + 입력창(500자). 내 댓글에 [수정] [삭제], 삭제된 댓글은 "삭제된 댓글입니다"
- 신고 창: 사유 선택(스포일러 미표시, 욕설·비방, 광고·스팸, 게임과 무관, 기타 + 직접 입력)

```
┌─────────────────────────────────────────────┐
│ ◀ 2026년 12월 ▶    플랫폼 [전체 ▼]           │
│ [달력 보기] [목록 보기]                       │
├─────────────────────────────────────────────┤
│ 12/3 (목)  [표지] 게임A   PC · PS5   [🔔]     │
│ 12/10 (목) [표지] 게임B   Switch     [🔔]     │
│ 12월 중    [표지] 게임C   PC         [🔔]     │
├─────────────────────────────────────────────┤
│ 날짜 미정·분기 단위                           │
│ 2027년 1분기 [표지] 게임D ...                 │
```

- [🔔]는 출시 알림 토글(REQ-204).

#### W-10 ~ W-12 커뮤니티

- W-10 게시글 목록: 게시판 탭, 정렬(최신·추천), 검색, [글쓰기]. 행: 제목 [댓글 수], 닉네임, 시간, 조회, 추천. 가려진 글은 목록에서 제외.
- W-11 게시글 상세: 제목, 작성자·시간·조회, 본문(이미지 포함), [추천] [신고], 본인 글 [수정] [삭제], 댓글.
- W-12 작성: 게시판 선택, 제목(100자), 본문 편집기(이미지 붙여넣기·업로드, 10개 이하, 1개 10MB), 오늘 포인트 한도 안내.

#### W-13 랭킹

- 탭: [주간 포인트] [월간 리뷰]. 기간 선택(이전 주·월).
- 1~3위 강조, 4~100위 목록(순위, 닉네임, 등급 아이콘, 점수). 로그인 상태면 하단에 "내 순위 23위" 고정.
- "매주 월요일 0시 집계" 같은 집계 기준 안내.

#### W-14 · W-15 이벤트

- W-14 목록: 탭 [진행 중] [예정] [종료]. 카드: 배너, 제목, 기간, 응모 포인트, 남은 자리.
- W-15 상세: 본문, 기간, 응모 포인트, 정원, [응모하기 (-500P)]. 응모 전 확인 창 "500P가 차감됩니다. 잔액 1,250P → 750P". 응모했으면 "응모 완료", 종료 후 당첨 여부 표시.
- 응모 불가 사유 표시: 포인트 부족, 기간 아님, 정원 마감(REQ-702).

### 3.2 내비게이션

```
┌─────────────────────────────┐
│ 게임평가단        [🔔] [출석]│  ← 상단 바 (홈 탭)
│                              │
│         (탭 화면)            │
│                              │
├─────────────────────────────┤
│  홈  │  게임  │ 출시일정 │ 마이 │  ← 하단 탭 4개
└─────────────────────────────┘
```

- 이벤트·랭킹·공지는 홈 탭과 마이 탭에서 들어간다.
- 출석 버튼은 상단 바에 두고, 앱을 열었을 때 오늘 출석하지 않았으면 홈에 출석 안내 카드를 띄운다.
